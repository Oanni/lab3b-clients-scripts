# Практическое задание 3Б 

## Файлы
- `index.html`
- `style.css` 
- `app.js` 

## Как запустить
Открыть `index.html` в браузере.

## Проверка
1. Нажать «Загрузить пользователей» - появятся 10 пользователей с именем, email и городом.
2. Введите в поиск «Leanne» - останутся подходящие записи; введите неизвестное имя - появится сообщение «Пользователи не найдены».
3. Нажми «Показать публикации» у любого пользователя - появятся заголовки и тексты первых трёх публикаций в отдельной области.
4. Проверка 404: замени в `app.js` адрес `USERS_URL` на `https://jsonplaceholder.typicode.com/userz` - появится ошибка. 
5. Все элементы работают, CSS-оформление присутствует.
